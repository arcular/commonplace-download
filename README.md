# Commonplace

A notes app for you and your friends. Keep **private notes** just for yourself, and share **group notes** that update for everyone. No subscription, no block limits.

## ⬇️ [Download Commonplace for Windows](https://github.com/arcular/commonplace-download/releases/latest/download/Commonplace-Setup.exe)

Windows 10 or 11 (64-bit) · about 115 MB

## Installing

1. Click the download link above.
2. If your browser says the file "isn't commonly downloaded", choose **Keep** (in Edge: **⋯ → Keep**; in Chrome: **Keep anyway**).
3. Open the downloaded file. If Windows says **"Windows protected your PC"**, click **More info → Run anyway**.
   (This only appears because the app is new and isn't signed with a paid certificate.)
4. Commonplace installs and opens by itself. There's nothing to set up.

## Getting started

- **Private notes:** choose *Private notes*. They're saved on your computer, and only you can see them.
- **Joining a friend's group:**
  1. Make a free [GitHub account](https://github.com/signup) and send your friend your GitHub username.
  2. Once they've invited you, choose *Join a group* and type the group code they sent you, for example `name/group-name`.
  3. Sign in with GitHub when the app asks.

Switch between your private notes and your groups from the top of the sidebar.

## Updating

Download and run the latest version from the link above. Your notes stay where they are.
